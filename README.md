# SPORT
Личная спортивная платформа для системного прогресса.

## Первый модуль
**Отжимания: 30 → 500 в день за 12 месяцев**
- 360-дневный трекер
- 10-дневные уровни прогрессии
- ежедневный счётчик повторений
- серия, общий объём и процент прохождения
- контроль веса, талии и максимума за подход
- данные хранятся локально в браузере

## Архитектура
Первый релиз — статический модульный frontend без сборщика, чтобы его можно было сразу публиковать на GitHub Pages. Интерфейс уже предусматривает модули: подтягивания, пресс, бег, растяжка и новые дисциплины.

Дальше проект можно развить до аккаунта, серверной синхронизации, истории замеров, графиков, фото прогресса, достижений и отдельных тренировочных программ.
